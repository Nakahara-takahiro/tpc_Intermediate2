# Python音シンセサイザー教材

中学生向けに、12回かけて「キー入力で演奏できるミニシンセサイザー」を作る教材です。
各回のテーマ・前回からの変更点・キーワード解説・改造チャレンジをまとめています。

---

## 共通モジュール

クラブのパソコンはWindows/Linuxが混在しているため、OSに依存する`winsound`は使わず、
どちらの環境でも同じように動く共通モジュールを2つ用意しています。
どちらも `lessonN_*.py` から `import` して使うだけで、モジュール自体は写経しません。

### `tone.py` (音を鳴らす)

- `play_tone(frequency, duration)`: 周波数[Hz]と時間[秒]を渡すと、その音を鳴らす。鳴らした波形データ(numpy配列)を返す。
- 第1〜2回はこの関数を呼ぶだけで音を鳴らす。中で `numpy` + `sounddevice` が何をしているかは、第3回で自分の手で書いて明かす。

### `oscilloscope.py` (波形を表示する)

- `show_waveform(wave, sample_rate, title="...")`: 波形データの最初の一部分を画面に表示(更新)する。呼ぶたびに、同じ画面の波形が新しい音に切り替わる。
- `keep_open()`: プログラムの最後に呼ぶと、画面を閉じるまで波形を表示したままにする。

第1・2・3・4・8・9・10・11・12回はこのモジュールを import して波形表示に対応しています。
第5・6・7回は、その回自体が「matplotlibで波形を見る」ことをテーマにしているため、既存の学習用コードをそのまま使い、`oscilloscope.py` は組み込んでいません。

## 第1回: 音を鳴らす基本 (`lesson1_play_tone.py`)

### テーマ
共通モジュール `tone.py` の `play_tone` 関数を使って単音を再生する。import・関数呼び出し・引数の意味を理解する。

### 前回からの変更点
- 新規作成。`tone.play_tone(周波数, 時間)` で音を鳴らす。
- `oscilloscope` モジュールを import し、鳴らした音の波形をオシロスコープ風に画面表示するようにした。

### キーワード解説
- **import**: 他の人が作った機能(ライブラリやモジュール)を自分のプログラムで使えるようにする命令。
- **関数呼び出し**: `play_tone(440, 1.0)` のように、名前と()で機能を実行すること。
- **引数(ひきすう)**: ()の中に書く、関数に渡す値。今回は「周波数」と「時間」。
- **周波数(Hz)**: 1秒間に波が何回振動するか。値が大きいほど高い音になる。
- **オシロスコープ**: 音の波形をリアルタイムで画面に映し出す装置。`oscilloscope.py` はそれをまねた仕組み。

### 改造チャレンジ
- **通常**: `440` の数字を変えて、高い音・低い音にしてみよう。鳴らす時間も変えてみよう。
- **上級(DACブース)**: 同じコードをDACブースで鳴らして、PC内蔵スピーカーとの音質の違いを聴き比べよう。

## 第3回: 波の正体 (`lesson3_sine_wave.py`)

### テーマ
`numpy` でサイン波のデータを作り、`sounddevice` で再生する。「波 = 数字の並び」であることを体感する。

### 前回からの変更点
- 第1〜2回で使っていた `tone.play_tone` の中身を、今回は自分の手で書く。
- 時間の配列 `t` とサイン波の配列 `wave` を `numpy` で作成し、`sounddevice` で再生するようにした。
- 再生後に `show_waveform` で、実際に鳴らした波形データをオシロスコープ画面に表示するようにした。

### キーワード解説
- **numpy**: 数字の並び(配列)を高速に計算できるライブラリ。
- **sounddevice**: 数字の並びを音として再生できるライブラリ。
- **サンプリングレート(sample_rate)**: 1秒間に何個のデータ(点)で音を表現するか。44100は音楽CDと同じ品質。
- **np.linspace**: 指定した範囲を、等間隔の点に分けて配列を作る関数。
- **np.sin**: サイン(正弦)の値を計算する関数。これが「波の形」を作るもとになる。

### 改造チャレンジ
- **通常**: `frequency` や `duration` の値を変えて、音の高さや長さを変えてみよう。
- **上級(DACブース)**: 同じサイン波をDACブースで再生して、音の純度(クリアさ)を聴き比べよう。

## 第4回: 周波数の計算 (`lesson4_frequency_calc.py`)

### テーマ
平均律の計算式を関数化し、音名(ド・レ・ミ…)から周波数を計算できるようにする。

### 前回からの変更点
- 周波数を直接書く代わりに、`note_to_freq` 関数で計算するようにした。
- 音名 → 半音差 の対応表(辞書 `note_names`)を作成。
- `play_note` 関数で、音名を渡すだけで音を鳴らせるようにした。
- `play_note` の中で `show_waveform` を呼び、鳴らした音名ごとに波形を画面表示するようにした。

### キーワード解説
- **平均律**: 1オクターブを12個の半音に均等に分ける音律。半音1つ上がるごとに周波数が
  2の12乗根(約1.0595)倍になる。
- **関数の定義(def)**: `def 関数名(引数):` で、自分だけの新しい関数を作ること。
- **return**: 関数の結果を呼び出し元に返す命令。
- **辞書(dict)**: `{"C4": -9, "D4": -7, ...}` のように、「名前」と「値」のペアを保存する箱。

### 改造チャレンジ
- **通常**: `note_names` に新しい音(D5やF#4など)を追加して、鳴らせる音を増やそう。
- **上級(DACブース)**: 半音階(ド→ド#→レ→…)を作ってDACブースで聴き、音の高さの変化を感じよう。

## 第6回: 波形の種類 (`lesson6_wave_shapes.py`)

### テーマ
矩形波・三角波を生成し、サイン波と見比べ・聞き比べる。

### 前回からの変更点
- `square_wave`(矩形波)と `triangle_wave`(三角波)を追加。
- 3つの波形を縦に並べてグラフ表示(`plt.subplots`)。
- 3つの波形を順番に再生して聞き比べる。

### キーワード解説

- **音色(おんしょく)**: 同じ高さの音でも、波形が違うと聴こえ方(音の質)が変わること。
- **subplots**: 複数のグラフを1つの画面に並べて表示する機能。

## 第7回: 倍音体験 (`lesson7_overtone.py`)

### テーマ
2つの波を足し算して、新しい波形を作る。倍音が音色を決めることを体感する。

### 前回からの変更点
- 基音(`fundamental`)と、その2倍の周波数の倍音(`overtone`)を作成。
- 2つの波を足し算して `combined` を作成。
- 音量が大きくなりすぎないよう正規化(`np.max`で割る)処理を追加。

### キーワード解説
- **基音(きおん)**: 音の高さを決める、もっとも基本となる周波数の波。
- **倍音(ばいおん)**: 基音の整数倍(2倍、3倍…)の周波数を持つ音。楽器ごとの音色の違いを生む。
- **正規化**: データの最大値を1にそろえて、音割れ(音が大きすぎて歪むこと)を防ぐ処理。

### 改造チャレンジ
- **通常**: 倍音の周波数(2倍→3倍)や混ぜる割合(`0.5`)を変えて、音色の変化を聴き比べよう。
- **上級(DACブース)**: 倍音を混ぜた音をDACブースで再生し、基音だけの音との違いを確認しよう。

## 第11回: エンベロープ (`lesson11_envelope.py`)

### テーマ
フェードイン・フェードアウトを追加し、音の立ち上がりと減衰を作る。

### 前回からの変更点
- `apply_envelope` 関数を追加。波の最初と最後の音量を `np.linspace` でなめらかに変化させる。
- `make_wave` の最後で `apply_envelope` を呼ぶようにした。
- `show_waveform` により、フェードイン部分がなめらかに立ち上がる波形の形をオシロスコープ画面で確認できるようにした。

### キーワード解説
- **エンベロープ**: 音量が時間とともにどう変化するかを表すもの。立ち上がり(フェードイン)と減衰(フェードアウト)が含まれる。
- **フェードイン/フェードアウト**: 音量を0から1へ、または1から0へなめらかに変化させること。
- **配列のスライス**: `wave[:fade_len]` や `wave[-fade_len:]` のように、配列の一部分を取り出す書き方。

### 改造チャレンジ
- **通常**: `fade_ratio` の値を変えて、フェードの長さを変えてみよう。エンベロープなしの音と聴き比べよう。
- **上級(DACブース)**: エンベロープあり・なしの音をDACブースで聴き比べ、印象の違いを発表しよう。

## 第12回: 完成・発表 (`lesson12_mini_synth.py`)

### テーマ
これまでの全機能(ミニ鍵盤・音色切替・エンベロープ・メロディ再生)を統合し、好きな曲を演奏して発表する。

### 前回からの変更点
- 音色切替キー(1,2,3)を追加し、演奏中に音色を変えられるようにした。
- メロディ(`melody`)と `play_melody` 関数を追加し、Mキーで自動演奏できるようにした。
- これまでの `make_wave` / `play_wave` / `apply_envelope` / `key_to_freq` をすべて統合した。
- `oscilloscope` モジュールも統合し、演奏中の波形をリアルタイムに近い感覚で画面表示するようにした。

### キーワード解説
- **統合**: これまで別々に作った機能を、1つのプログラムにまとめること。
- **time.sleep**: 指定した時間だけ処理を一時停止する関数。キーの誤反応(連続入力)を防ぐために使用。
- **発表会**: 自分のシンセサイザーで演奏した音を、DAC+スピーカーを使ったシステムでみんなに聴いてもらう場。

### 改造チャレンジ
- **通常**: `melody` を好きな曲のメロディに変更し、自分なりの演奏を完成させよう。
- **上級(DACブース)**: 完成したミニシンセサイザーで、DAC+スピーカーを使って発表しよう。
