# Python音シンセサイザー教材

中学生向けに、12回かけて「キー入力で演奏できるミニシンセサイザー」を作る教材です。
各回のテーマ・前回からの変更点・キーワード解説・改造チャレンジをまとめています。

---

## 共通モジュール・デモ教材

クラブのパソコンはWindows/Linuxが混在しているため、OSに依存する`winsound`は使わず、
どちらの環境でも同じように動くコードで揃えています。

### `tone_util.py` (音を鳴らす)

- `play_tone(frequency, duration)`: 周波数[Hz]と時間[秒]を渡すと、その音を鳴らす。鳴らした波形データ(numpy配列)を返す。
- 第1〜2回はこの関数を呼ぶだけで音を鳴らす。
- 中身は実質3行と短いので、**第1回に生徒自身が手打ち**する。ここで打った `np.sin(...)` が何なのかは、第3回の `circle_wave_demo.py` で明かす。

### `oscilloscope.py` (波形を表示する) ※写経対象外

- `show_waveform(wave, sample_rate, title="...")`: 波形データの最初の一部分を画面に表示(更新)する。呼ぶたびに、同じ画面の波形が新しい音に切り替わる。
- `keep_open()`: プログラムの最後に呼ぶと、画面を閉じるまで波形を表示したままにする。

第1・2・3・8・9・10・11・12回はこのモジュールを import して波形表示に対応しています。
第5・6・7回は、グラフを描くコード(`plt.subplots` など)を自分で書くこと自体が学習内容のため、`oscilloscope.py` は組み込んでいません。

### `circle_wave_demo.py` (円が波になる様子を見る) ※写経対象外

- 第3回の前半で使うデモ教材。**GitHubからダウンロードして実行するだけ**で、写経はしない。
- 左に単位円、右に波を並べて表示し、円周上を一定の速さで回る点の「高さ」がそのままサイン波になる様子を animation で見せる。
- ファイル冒頭の `amplitude`(波の大きさ=円の半径)と `frequency`(1秒あたりの回転数)を書き換えて実行し直すことで、波形がどう変わるかを生徒自身が確かめる。
- 最後に440Hzのサイン波を実際に鳴らし、「目で見た波」と「耳で聞く音」が同じものであることにつなげる。

## 第1回: 音を鳴らす基本 (`lesson1_play_tone.py`)

### テーマ
共通モジュール `tone.py` の `play_tone` 関数を使って単音を再生する。import・関数呼び出し・引数の意味を理解する。

### 前回からの変更点
- 新規作成。`tone.play_tone(周波数, 時間)` で音を鳴らす。
- `oscilloscope` モジュールを import し、鳴らした音の波形をオシロスコープ風に画面表示するようにした。

### キーワード解説
- **import**: 他の人が作った機能(ライブラリやモジュール)を自分のプログラムで使えるようにする命令。
- **関数呼び出し**: `play_tone(440, 1.0)` のように、名前と()で機能を実行すること。
- **引数(ひきすう)**: ()の中に書く、関数に渡す値。今回は「周波数」と「時間」。
- **周波数(Hz)**: 1秒間に波が何回振動するか。値が大きいほど高い音になる。
- **オシロスコープ**: 音の波形をリアルタイムで画面に映し出す装置。`oscilloscope.py` はそれをまねた仕組み。

### 改造チャレンジ
- **通常**: `440` の数字を変えて、高い音・低い音にしてみよう。鳴らす時間も変えてみよう。
- **上級(DACブース)**: 同じコードをDACブースで鳴らして、PC内蔵スピーカーとの音質の違いを聴き比べよう。

## 第3回: 波の正体と周波数の計算 (`circle_wave_demo.py` + `lesson3_frequency_calc.py`)

第3回は「見る前半」と「書く後半」の2部構成です。

### 前半: 円が波になるのを見る (`circle_wave_demo.py` / 写経なし)

#### テーマ
円周上を一定の速さで回る点の「高さ」が、そのままサイン波になることを目で確かめる。
第1回から打ってきた `np.sin(2 * np.pi * frequency * t)` が何をしていたのかを明かす。

#### 進め方
1. GitHubから `circle_wave_demo.py` をダウンロードして、そのまま実行する。
2. 左の円を点が回り、その高さが右に流れて波になる様子を観察する。
3. 画面いちばん下の「周波数」スライダーを実行中にドラッグし、波形の変化を確かめる。
   - スライダーを右に動かす(周波数を大きくする) → 回転が速くなり、波が細かく詰まる。
   - 「1秒に何回転するか」がそのまま周波数。**これを1秒に440回転させたものが「ラ」の音**であることを説明する(実際に「ラ」の音を鳴らすのは後半の `lesson3_frequency_calc.py`)。
4. 波の大きさ(振幅)を変えたいときは、ファイル冒頭の `amplitude` の数字を書き換えて実行し直す。
   - `amplitude` を大きくする → 円が大きくなり、波の高さ(振幅)が増える。

#### キーワード解説
- **サイン(sin)**: 円を回る点の「高さ」を表すもの。三角形の話ではなく、まずは「円を回る点の高さ」と覚えてよい。
- **振幅(しんぷく)**: 波の高さ。円の半径にあたる。大きいほど音が大きい。
- **周波数(Hz)**: 1秒間に何回転するか。大きいほど波が細かくなり、音が高い。
- **角速度**: 点が回る速さ。これが周波数そのもの。

### 後半: 音名から周波数を計算する (`lesson3_frequency_calc.py` / 写経)

#### テーマ
平均律の計算式を関数化し、音名(ド・レ・ミ…)から周波数を計算できるようにする。

#### 前回からの変更点
- 周波数を直接書く代わりに、`note_to_freq` 関数で計算するようにした。
- 音名 → 半音差 の対応表(辞書 `note_names`)を作成。
- `play_note` 関数で、音名を渡すだけで音を鳴らせるようにした。
- `play_note` の中で `show_waveform` を呼び、鳴らした音名ごとに波形を画面表示するようにした。

#### キーワード解説
- **平均律**: 1オクターブを12個の半音に均等に分ける音律。半音1つ上がるごとに周波数が
  2の12乗根(約1.0595)倍になる。
- **関数の定義(def)**: `def 関数名(引数):` で、自分だけの新しい関数を作ること。
- **return**: 関数の結果を呼び出し元に返す命令。
- **辞書(dict)**: `{"C4": -9, "D4": -7, ...}` のように、「名前」と「値」のペアを保存する箱。

### 改造チャレンジ
- **通常**: `note_names` に新しい音(D5やF#4など)を追加して、鳴らせる音を増やそう。
- **通常(前半)**: `circle_wave_demo.py` で「波の山が2つだけ見える設定」を自分で見つけよう。
- **上級(DACブース)**: 半音階(ド→ド#→レ→…)を作ってDACブースで聴き、音の高さの変化を感じよう。

## 第5〜7回の流れ: 波形 = 音色

第5回から第7回までは、3回続けて「波形と音色の関係」を考えます。

| 回 | すること | わかること |
|----|----------|------------|
| 5 | 3つの波形を見比べ・聞き比べ、ドレミを弾く | 形が違うと音色が違う。音の高さと音色は別のもの |
| 6 | サイン波を足し算して矩形波を組み立てる | 形の違いは、中に混ざっているサイン波(倍音)の違い |
| 7 | 倍音の混ぜ方(レシピ)を自分で決める | 倍音を混ぜれば、自分だけの音色が作れる |

### 前回からの変更点

## 第6回: 矩形波を組み立てる (`lesson6_build_square.py`)

### テーマ
「なぜ形が違うと音色が違うのか?」に答える。サイン波を足し算して矩形波を組み立て、
グラフの形と聞こえる音色が同時に矩形波へ近づいていく様子を確かめる。

### 前回からの変更点
- ドレミの演奏部分を削除し、お手本の矩形波(`square_wave`)を作るところまで残した。
- `harmonics = [1, 3, 5, 7, 9]` の順に、n倍の周波数のサイン波を 1/n の大きさで `built_wave` に足していく `for` 文を追加。
- 1つ足すたびに、グラフ(灰色=お手本の矩形波、青=組み立て中の波)を表示し、その音を鳴らす。
- 最後にお手本の矩形波を鳴らして、組み立てた音と聞き比べる。

### キーワード解説
- **倍音(ばいおん)**: 基音の整数倍(2倍、3倍…)の周波数を持つ音。
- **基音(きおん)**: 音の高さを決める、もっとも基本となる周波数の波(今回は1倍の音)。
- **enumerate**: `for i, n in enumerate(リスト):` と書くと、中身(`n`)と一緒に「何番目か」(`i`)も取り出せる。
- **np.zeros_like**: 同じ長さで、中身がすべて0の配列を作る。足し算のスタート地点。
- **plt.pause**: グラフをいったん画面に表示し、少し待つ命令。

### 改造チャレンジ
- **通常**: `harmonics` に 11, 13, 15 … と足していき、音とグラフがどこまで矩形波に近づくか確かめよう。
- **通常**: `harmonics` を `[1, 2, 3, 4, 5, 6, 7, 8, 9]` にすると、新しい形の波(ノコギリ波)ができる。音色も聞いてみよう。
- **上級(DACブース)**: 組み立て途中の音をDACブースで聴き、倍音が増えるごとの音色の変化を説明しよう。

## 第7回: 倍音体験 ― 自分だけの音色を作る (`lesson7_overtone.py`)

### テーマ
倍音をどれだけ混ぜるかをリスト(レシピ)で決め、自分だけの音色を作る。倍音の混ざり方が音色を決めることを体感する。

### 前回からの変更点
- 決まった足し方(`harmonics`)の代わりに、1倍・2倍・3倍…の混ぜる量を並べたリスト `recipe` を作った。
- レシピどおりに足し算する `make_recipe_wave` 関数を追加。
- 音量が大きくなりすぎないよう正規化(`np.max`で割る)処理を追加。
- レシピを棒グラフ(`bar`)、できた波形を折れ線グラフで並べて表示する。
- 自分の音色でドレミファソラシドを演奏する。

### キーワード解説
- **レシピ(recipe)**: どの倍音をどれだけ混ぜるかを並べたリスト。これを変えると音色が変わる。
- **正規化**: データの最大値を1にそろえて、音割れ(音が大きすぎて歪むこと)を防ぐ処理。
- **棒グラフ(bar)**: 量の大小を棒の長さで表すグラフ。倍音ごとの混ぜる量を見るのに使う。

### 改造チャレンジ
- **通常**: `recipe` の数字を変えて、自分だけの音色を作って発表しよう。
- **通常**: `recipe = [1, 0, 1/3, 0, 1/5, 0, 1/7]` にすると、第6回で組み立てた矩形波に近い音になることを確かめよう。
- **上級(DACブース)**: 自分のレシピの音をDACブースで再生し、基音だけの音との違いを確認しよう。

## 第11回: エンベロープ (`lesson11_envelope.py`)

### キーワード解説
- **エンベロープ**: 音量が時間とともにどう変化するかを表すもの。立ち上がり(フェードイン)と減衰(フェードアウト)が含まれる。
- **フェードイン/フェードアウト**: 音量を0から1へ、または1から0へなめらかに変化させること。
- **配列のスライス**: `wave[:fade_len]` や `wave[-fade_len:]` のように、配列の一部分を取り出す書き方。
